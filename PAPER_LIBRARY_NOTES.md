# SQLViz Competitive Exam Paper Library

The Competitive Exam Practice module now includes a built-in catalogue of year-labelled links to GATE and JEE Main question-paper sources, as well as support for uploading question-paper page images.

## Sources included in the catalogue

- GATE CS 2023 — official IIT Kanpur question-paper PDF: https://gate.iitk.ac.in/GATE2023/doc/papers/2023/CS_GATE2023.pdf
- GATE 2024 — official IISc Bengaluru website: https://gate2024.iisc.ac.in/
- GATE 2025 — official IIT Roorkee download page: https://gate2025.iitr.ac.in/download.html
- GATE previous-year archive (including 2022): https://gate2026.iitg.ac.in/download.html
- JEE Main 2024 shift-wise paper directory: https://www.study4india.com/question-paper/previous-year/jee-main/2024/
- JEE Main official NTA website: https://jeemain.nta.nic.in/

Important: these catalogue entries link to official paper PDFs or source pages; they are not bundled page-image scans. The module's separate image upload area accepts JPG, PNG, and WEBP files. Images uploaded through the browser are stored in that browser's IndexedDB and do not automatically become project files. For a strict offline/image-only submission, download the desired paper pages, export them as images, and place them in a project assets folder and wire them into the catalogue.

## Team portraits

The supplied ZIP did not contain team portrait images. The only non-library image asset found in `src/assets` was `hero.png`, a decorative abstract graphic, plus the standard React/Vite SVG assets. The Developed By page therefore uses initials avatars as placeholders instead of broken portrait links.
